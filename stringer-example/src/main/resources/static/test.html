Stringer 域（profile）场景对比台 同一套工具注册表 —— 只有"本轮所处的域"不同
全域工具（未声明 profiles） 管理域工具（profiles={"admin"}） 需二次确认
🙋 客服域
profile = "customer"
水果订阅的客服视角。模型能看到 天气（显式声明通配 * ＝ 全域可见）+ 订单查询 （customer 专属）；管理域的经营数据、关单都不在它的视野内。 试着问它"今天卖了多少单"，看它手上有没有这个能力。
今天天气 查订单 今天卖了多少单？
Enter 发送 · Shift+Enter 换行
🛡️ 管理域
profile = "admin"
运营视角。在"天气"（通配 *，全域可见）之上，额外可用 经营数据 与 关单； 关单是写操作，提交后会弹二次确认。反过来，查订单是客服域专属，这里拿不到。
经营数据 关单（需确认） 查订单（客服专属）
Enter 发送 · Shift+Enter 换行
