「所属域」写法：全域 ＝ 该工具显式声明了通配 "*"，对每个域都可见； 显式域名 ＝ 只在这些域可用；留空 ＝ 只属于兜底域 default（不再等于全域可见）。 域是授权边界：域侧只能在声明范围内决定用不用，不能把工具拉进未授权的域。
