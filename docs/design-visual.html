编排循环读法：每进入 3.1 就是一次完整 LLM 调用；LLM 产出 AiMessage 后才进入 3.2 做条件边匹配（三选一）；auto 走 3.4 执行工具，执行完经固定边（蓝色实线）立刻回到 3.1 再次调用 LLM —— 这条回边不经过条件边，因为此刻末条消息是工具结果而非模型输出。review 分支的 resume 放行后同样汇入 3.4，再经固定边回到 3.1。

域读法：4.1 工具的可用域由工具侧声明（注解的 domains，留空＝只属于兜底域 default；"*"＝全域可用）；4.2 域有三个来源 —— 内置 default、管控台人工创建（落盘可增删）、工具声明派生，一经声明即常驻，工具下线不会让域消失；4.3 每次对话按请求携带的域实时过滤出可见工具集与同源的需审批集，连同域提示词一起注入模型。
