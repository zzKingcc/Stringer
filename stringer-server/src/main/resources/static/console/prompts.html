提示词设定

系统提示词 = 公共基线 + 域差异。域差异可以留空（留空就只用基线）。 域有三种来源：内置兜底域 default、管控台人工创建、工具声明派生； 本页只编辑提示词，新建与删除域在域空间。

可见工具与提示词的关系
可见工具 = 该域真实能用的工具集（显式声明通配 * 的工具对所有域可见； 声明留空的工具只属于兜底域 default，不会出现在其他域里）。 提示词不决定工具可见性：就算某个域一个字都没配，它对工具的限制照样生效，缺提示词只是体验降级。
